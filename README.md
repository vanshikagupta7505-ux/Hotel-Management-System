# 🏨 Hotel Management System

A web-based Hotel Management System developed using PHP and MySQL.

## Features
- User Registration and Login
- Admin Dashboard
- Room Management
- Room Booking
- Customer Management
- Food Ordering
- Booking Management
- Payment Management

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## Database
Database Name: hotel_db

SQL File: database/hotel_db.sql

## Installation
1. Install XAMPP.
2. Copy the project folder into htdocs.
3. Start Apache and MySQL.
4. Open phpMyAdmin.
5. Create database named hotel_db.
6. Import database/hotel_db.sql.
7. Configure the database connection.
8. Open localhost/Hotel-Management-System in your browser.
